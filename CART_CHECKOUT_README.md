# Bookly Cart & Checkout

Implemented without changing the existing visual theme.

## Included
- Add products to cart from the homepage.
- Persistent cart using browser localStorage.
- Dynamic cart count and mini-cart in the header.
- Cart page with quantity +/- controls and remove.
- Automatic subtotal, shipping and total calculation.
- Checkout page with required customer fields.
- Cash on Delivery / demo online-payment selection.
- Front-end order placement with generated demo order number.
- Cart is cleared after a successful demo order.

## Important
This is currently a front-end implementation. It does not charge a card, save orders to a server, or connect to a payment gateway. A backend/API and a payment provider can be added next without changing the cart UI.
