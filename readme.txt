# 📚 Bookstore E-Commerce Website

A responsive bookstore e-commerce website built using **HTML, CSS, and JavaScript**.  
The project provides a modern online bookstore interface with product browsing, book details, shopping cart, checkout, and multiple supporting pages.

## 🚀 Features

- 📖 Browse books and products
- 🔍 Product and book browsing interface
- 🛒 Shopping cart page
- 💳 Checkout page
- 📚 Individual product/book details
- 📰 Blog and individual blog post pages
- ℹ️ About page
- 📞 Contact page
- 📱 Responsive website layout
- ✨ Interactive user interface
- 🎨 Modern bookstore-themed design
- 🖼️ Product and book image galleries

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, responsiveness, and UI design
- **JavaScript** – Interactive functionality and dynamic behavior
- **Git & GitHub** – Version control and project hosting

##📄 Pages
🏠 Home

The main landing page of the bookstore website featuring the store's content, products, and navigation.

🛍️ Shop

Displays the bookstore's available products in a dedicated shopping interface.

📖 Single Product

Provides a detailed view of an individual book or product.

🛒 Cart

Displays products added to the shopping cart and provides cart-related actions.

💳 Checkout

Provides the checkout interface for reviewing the order and entering checkout information.

ℹ️ About

Contains information about the bookstore and its purpose.

📰 Blog

Displays bookstore-related blog content.

📝 Single Post

Displays the complete content of an individual blog post.

📞 Contact

Provides a contact page for users to get in touch.

📱 Responsive Design

The website is designed to provide a responsive experience across different screen sizes, including:

💻 Desktop
📱 Mobile
📟 Tablet
⚙️ How to Run Locally
1. Clone the repository
git clone https://github.com/aashimangla/bookstore-ecommerce.git
2. Open the project
cd bookstore-ecommerce
3. Run the website

You can open index.html directly in your browser.

For development, VS Code Live Server can be used for easier testing and automatic browser refresh.
