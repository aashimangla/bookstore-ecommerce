# 📚 Bookstore E-Commerce Website

A responsive and interactive **Bookstore E-Commerce Website** built using **HTML, CSS, and JavaScript**. The project provides a complete shopping experience with book browsing, search, genre filtering, cart management, and checkout functionality.

## 🚀 Features

* 📖 **Book Catalog** – Browse books across different genres and categories
* 🔍 **Book Search** – Search for books directly from the website
* 🏷️ **Genre Filtering** – Explore books based on their genre
* 🛒 **Shopping Cart** – Add, remove, and update books in the cart
* 💰 **Dynamic Cart Total** – Automatically calculates item quantities and total price
* 📦 **Checkout Page** – Review selected books and order details before checkout
* ❤️ **Wishlist UI** – Save books for later
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile screen sizes
* 🧩 **Reusable Header Component** – Shared navigation/header across multiple pages
* ✨ **Interactive UI** – Dynamic navigation, search, cart updates, and page interactions

## 🛠️ Tech Stack

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript (ES6+)** – Dynamic functionality and user interactions
* **Git & GitHub** – Version control and project management

## 🖥️ Pages

### Home

The landing page showcasing featured books, genres, and navigation to different sections of the store.

### Shop

Displays the available books with search and genre-based browsing.

### Cart

Allows users to view selected books, change quantities, remove items, and see the updated total.

### Checkout

Provides a final order review before completing the purchase.

## 🔍 Search & Filtering

The website includes client-side book search functionality. Users can search for books by title and browse books according to their genre.

## 🛒 Shopping Cart

The cart system allows users to:

* Add books to the cart
* Remove books from the cart
* Increase or decrease quantities
* View the number of items in the cart
* Automatically update the total price

## 📱 Responsive Design

The interface is designed to adapt to different screen sizes, providing a consistent browsing experience on:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/aashimangla/bookstore-ecommerce.git
```

### 2. Open the project

```bash
cd bookstore-ecommerce
```

### 3. Run the website

Since this is a frontend project, you can open `index.html` directly in a browser.

For the best development experience, use **VS Code Live Server**.
