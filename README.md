# 📚 Bookstore E-Commerce Website

A responsive bookstore e-commerce website built using **HTML, CSS, and JavaScript**. The project provides a modern interface for browsing books, viewing product details, managing a shopping cart, and going through the checkout process.

## 🚀 Features

- 📖 Browse books and products
- 🛍️ Dedicated shop page
- 📚 Individual product/book pages
- 🛒 Shopping cart interface
- 💳 Checkout interface
- 📰 Blog section
- 📝 Individual blog post pages
- ℹ️ About page
- 📞 Contact page
- 📱 Responsive design for different screen sizes
- ✨ Interactive and modern user interface

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, responsiveness, and UI design
- **JavaScript** – Interactive functionality and dynamic behavior
- **Git & GitHub** – Version control and project hosting

## 📄 Pages

### 🏠 Home

The main landing page of the bookstore website featuring the store's content, products, and navigation.

### 🛍️ Shop

Displays the available books and products in a dedicated shopping interface.

### 📖 Single Product

Provides detailed information about an individual book or product.

### 🛒 Cart

Displays products added to the shopping cart and provides cart-related actions.

### 💳 Checkout

Provides the checkout interface for reviewing an order and entering checkout information.

### ℹ️ About

Contains information about the bookstore and its purpose.

### 📰 Blog

Displays bookstore-related blog content.

### 📝 Single Post

Displays the complete content of an individual blog post.

### 📞 Contact

Provides a page for users to get in touch.

## 📱 Responsive Design

The website is designed to provide a responsive experience across different screen sizes:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/aashimangla/bookstore-ecommerce.git
```

### 2. Open the project

```bash
cd bookstore-ecommerce
```

### 3. Run the website

Open `index.html` directly in your browser.

For development, you can use **VS Code Live Server** for easier testing and automatic browser refresh.
